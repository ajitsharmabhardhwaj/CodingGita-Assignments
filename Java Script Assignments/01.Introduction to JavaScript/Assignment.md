Section-B
1.JavaScript is a statically typed language.
  False
 JavaScript is a dynamically typed language, meaning variable types are determined at runtime.

 2.JavaScript can only run inside the browser.
  False
 JavaScript can also run outside the browser using environments like Node.js.

 3.HTML is responsible for the behaviour of a webpage.
  False
 HTML provides the structure of a webpage. JavaScript is responsible for behavior and interactivity.

 4.Node.js allows JavaScript to run outside the browser.
  True
 Node.js is a runtime environment that lets JavaScript run on servers and local machines.

 5.JavaScript is case-insensitive.
  False
 JavaScript is case-sensitive. name and Name are treated as different identifiers.

 6.let name and let Name are the same variable.
  False
 Because JavaScript is case-sensitive, name and Name are two different variables.

 7.ECMAScript is a programming language.
  False
 ECMAScript is the standard specification on which JavaScript is based, not a separate programming language in common use.
 
 8.React, Angular, and Vue.js are used for Backend development.
  False
 React, Angular, and Vue.js are Frontend JavaScript frameworks/libraries used to build user interfaces.

Answer-15
1.Event Handling=>
JavaScript can respond to user actions such as clicks, key presses, mouse movements, and form submissions.

Example: When a user clicks a button, JavaScript can display a message or open a menu.

2.DOM Manipulation=>
JavaScript can access and modify the content, structure, and style of a web page without reloading it.

Example: Updating text, changing colors, or adding new elements dynamically when a user interacts with the page.
