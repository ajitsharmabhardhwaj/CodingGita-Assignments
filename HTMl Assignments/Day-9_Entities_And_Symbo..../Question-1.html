In HTML, the less-than symbol is written as &lt;, which displays as < in the browser.

The greater-than symbol is written as &gt;, which displays as > in the browser.

The ampersand symbol is written as &amp;, which displays as & in the browser.

Using hexadecimal, the less-than symbol is written as &#x3C;, which displays as <.

The greater-than symbol in hexadecimal is &#x3E;, which displays as >.

The ampersand symbol in hexadecimal is &#x26;, which displays as &.
